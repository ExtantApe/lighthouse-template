# Name ideas

Offer a theme, then four or five names from it or in its spirit, at least one funny. Names start with a lowercase letter,
then letters, digits and hyphens.

| Theme | Straight | Funny |
| --- | --- | --- |
| Small boats | skiff, dinghy, coracle, punt, kayak | bathtub, pool-noodle, soggy-raft |
| Weather | squall, doldrums, gale, mistral, zephyr | drizzle, mild-breeze, partly-cloudy |
| Sea creatures | narwhal, octopus, manta, nautilus | sea-cucumber, grumpy-crab, damp-otter |
| Knots | bowline, clove-hitch, sheepshank, figure-eight | granny-knot, tangled-mess |
| Lighthouse things | lantern, beacon, fresnel, gallery | wick, foghorn, keepers-cat |
| Navigation | sextant, compass, astrolabe, log-line | wrong-turn, lost-sock, recalculating |

A Lamplighter's name tends to sound like a place (harbor, breakwater, quay). A vessel's tends to sound like something
that moves.
